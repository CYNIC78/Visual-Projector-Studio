## 1. Исходная позиция (зафиксировано владельцем)

- **Визуальная онтология:** проект работает в перспективе **от первого лица (POV)**.
  Фокус визуала — мир и персонаж под управлением модели; модель сама иллюстрирует
  сценарий ассетами активного таба.
- **Отказ от «бесшовного 3D-блендинга» для видео:** попытки склеивать видеоклипы
  встык без швов (или принудительно возвращать каждый клип в нейтральную позу ради
  цикла) — тупиковый путь для 2D/AI-видео. Это не 3D-анимация со скелетным blending.
- **Принятый принцип переходов:** видео-ассеты живут на **тех же переходах проектора**,
  что и статика (кроссфейды, `fade`, выталкивание и т.д.).
- **Базовый живой паттерн:** микс статики и коротких видео — *статичный кадр →
  статичный кадр → анимированная эмоция/жест (2–5 сек) → статичный кадр*, склеенные
  стандартными переходами.
- **Производственный контекст (ComfyUI / Minimax H3 Q4_M / Wan 2.2):** локальный
  ComfyUI бодро генерирует в фоне ролики до **10 сек, 24 fps, ~0.5 МП со звуком**
  (на квантах Q4_M без удушения системы). Из одного ролика (до ~240 кадров)
  можно дополнительно нарезать идеально согласованные по внешности и свету
  статичные кадры для галереи и секвенций.
- **Рекомендуемые пропорции (~0.5 МП):**
  - **3:4 (`624×832` или `608×816`)** — универсальный портрет под вертикальный
    пристыкованный `Stage` + аккуратно работает в `Focus 4:3` (с панорамированием
    верх/низ без потери резкости).
  - **2:3 (`576×864`)** — чуть выше, под полный рост / узкий вертикальный Stage.
  - **4:3 (`832×624`)** — идеален для сцен окружения, парных сцен и 1-к-1 в
    `Focus 4:3`.
  - Для видео в ComfyUI 0.5 МП на экране Stage (типичная ширина 380–550 px)
    выглядит чётко и отлично держит бюджет памяти/диска; для ключевых статичных
    портретов с 1.5× зумом в Focus можно при желании оставлять ~1 МП (`768×1024`).

## 2. Секвенции ассетов (`[SEQ:...]`) — динамическая хореография

### Проблема сейчас
Если модель выдаёт несколько `[IMG:...]` в одном ответе, `VPCommandBus` исполняет
их почти мгновенно — зритель видит только последний кадр.

### Концепт
- **Компактная грамматика** (простая для локальных 12B–26B моделей):
  `[SEQ:tag1,tag2,tag3,tag4:tempo]` (опц. модификатор `loop` / `pingpong`).
  - `tempo`: `slow` (~2.2с), `med` (~1.3с), `fast` (~0.65с).
  - В секвенции могут участвовать как статичные ассеты, так и видео-ассеты (микс).
    Для видео длительность шага задаётся естественным окончанием клипа (`ended`),
    для статики — параметром `tempo`.
- **Opt-in через `tab.rules` (нулевая диета токенов):** никаких глобальных
  инструкций в базовом манифесте. Секвенции активируются прямо в правилах
  конкретного таба (например, таб «Танец» или «Бой»): *«иллюстрируй движения
  секвенцией `[SEQ:...:fast]` из 4–8 кадров, текст пиши коротко»*.
- **Жизненный цикл:** любой новый `[IMG:]`, новый `[SEQ:]` или смена активного таба
  чисто останавливает предыдущую секвенцию.
- **Точка стыка с будущей FSM / слоем ресурсов:** на каждом шаге секвенция эмитит
  события в `VP_HUB` (`seq:step`, `seq:completed`, `seq:interrupted`). Это позволяет
  игре/FSM проверять ресурсы (стамина, баланс и т.д.) между шагами и при провале
  прерывать цепочку с показом fail-кадра и эхом `[SCENE EVENT]` в контекст модели.

## 3. Видео-ассеты в проекторе — техническая оценка

### Потянет ли система (Neutralino 6.8 / Edge WebView2)?
**Да, с большим запасом.**
- Ролики 640×960 @ 16 fps (2–3 МБ) декодируются аппаратным блоком GPU (NVDEC),
  не конкурируя за VRAM/вычисления с `llama.cpp` и `sd.cpp`.
- В `visual-projector.js` (`updateProjectorUI`) все переходы сделаны на CSS между
  уходящим и входящим DOM-элементом. Замена `<img>` на `<video autoplay muted playsinline>`
  автоматически даёт все существующие переходы для пар `img↔video` и `video↔video`.

## 4. Узкие места (проверено по коду) и решения

| # | Узкое место в текущем коде | Симптом, если не учесть | Решение по уму |
|---|---|---|---|
| **1** | **Загрузка мира в RAM** (`vp-storage-native.js:588`) | Все файлы `assets/files/` читаются через `FS.readBinaryFile` (WebSocket + base64) целиком при старте мира. 50–100 клипов по 3 МБ затормозят старт и раздуют RAM. | При старте мира для видео грузить только лёгкий **JPEG-постер (~30 КБ)**; сам файл видео отдавать лениво при показе (через встроенный HTTP-сервер Neutralino `:45710` или ленивый `readBinaryFile` с LRU-кешем на 5–6 клипов). |
| **2** | **VLM-каналы, одинаковые стартовые кадры I2V и `ensureBase64()`** (`visual-projector.js:783`, `projector-tagger.js`, `gallery-collage.js`) | `ensureBase64()` превратит MP4 в base64 и уронит запрос к `llama-server`. Вдобавок при I2V стартовый кадр (`0.0s`) у десятка роликов часто одинаковый — в коллаже они будут неразличимы. | При импорте авто-постер снимать с **~45% длительности** (когда действие уже развернулось), а в превью видео дать ползунок + кнопки **`🖼 На обложку`** (выбор характерного кадра для галереи/коллажа/VLM) и **`📸 Сохранить как кадр`**. Весь VLM-слой работает только с постером (+ бейдж `🎬 10s`). |
| **3** | **Чёрная вспышка и скачок на кроссфейде `<video>`** (`visual-projector.js:1665`) | Новый `<video>` может 20–100 мс декодировать первый кадр; а если повесить в `poster` кадр из середины ролика, на старте мигнёт середина перед прыжком на `0.0s`. | Выбранный обложечный постер использовать для галереи/коллажа/VLM; в самом плеере перед стартом CSS-перехода дождаться события `loadeddata` первого реального кадра (с диска ~20–40 мс) — ноль чёрных вспышек и ноль ложных кадров. |
| **4** | **Поведение после окончания клипа** | Бесконечный `loop` для жеста/эмоции («кивает как болванчик 2 минуты») раздражает; для фона (ветер, дыхание, танец) `once` наоборот обрывает жизнь. | Простое поле ассета `playMode: 'once' | 'loop'` (дефолт **`once`** — проиграл жест и замер на последнем кадре; `loop` включается для фоновых клипов). Нативный `pingpong` для `<video>` **не строить** (обратный `playbackRate` в Chromium дёргает). |
| **5** | **Конфликт `fadeDuration` и быстрого темпа `[SEQ:...:fast]`** | При глобальном `fadeDuration = 1.2s` и шаге `0.6s` кадры наслаиваются в 3 слоя и превращаются в кашу. | Внутри секвенции автоматически ограничивать длительность перехода: `Math.min(fadeDuration, stepMs * 0.45)`. |
| **6** | **Спам истории и dirty-флага при секвенции** (`setCurrent`) | Каждый шаг `[SEQ]` через обычный `setCurrent` будет писать в `State.history`, дёргать `DB.setCurrentTag` и зажигать «Не сохранено». | Промежуточные шаги секвенции помечать тихим флагом (без записи дублей в `State.history` и без спама в storage); в историю попадает только сам факт запуска / финальный кадр. |
| **7** | **Кодеки ComfyUI (Wan 2.2)** | 10-bit `yuv444p` или HEVC/H.265 из ComfyUI в Edge WebView2 часто дают чёрный экран без ошибки. | Экспорт из ComfyUI в **MP4 (H.264 / `yuv420p`, 8-bit)** (уже настроено владельцем) или **WebM (VP9)**; при `video.onerror` показывать понятный тост и фолбэк на постер. |
| **8** | **Совместимость с Focus / 2.5D Depth / ZIP-экспортом** | 2.5D Depth ждёт статичную depth-карту; `JSZip` при `DEFLATE` на MP4/MP3/OGG зря жжёт CPU; Focus Snapshot ждёт `<img>`. | Для видео: 2.5D Depth тихо пропускается (плоский рендер); в `JSZip` для `.mp4`/`.webm`/`.mp3`/`.ogg`/`.opus` ставить `compression: 'STORE'` (без пересжатия); Focus Snapshot снимает текущий кадр прямо с `<video>` на `<canvas>`. |
| **9** | **Автозапуск и звук видео (WebView2 autoplay policy)** | Ролики Minimax H3 идут **со звуком**; до первого пользовательского жеста в окне браузер может заблокировать немой/звуковой автозапуск, плюс пользователю нужен быстрый Mute. | В плеере Stage — компактная кнопка **🔊 / 🔇 Mute** + ползунок громкости (единый для звука видео и будущего аудио-слоя). После первого клика/сообщения звук играет сразу; до первого жеста при ошибке `play()` — тихий фолбэк в `muted = true` без сбоя. |

## 5. Аудио-ассеты — фоновая музыка, эмбиент и SFX (не TTS)

> Задумка владельца (2026-11-24): добавлять в табы аудио-ассеты (эмбиент сцены,
> музыка под танец/секвенцию, звуковые эффекты). Без TTS — чисто атмосфера и динамика.

### 5.1 Двухуровневая модель (автомат FSM + опциональное управление моделью)

Чтобы не перегружать локальную модель и не тратить лишние токены, аудио делится
на два слоя:

1. **Автомат таба / секвенции (0 токенов, модель не напрягается):**
   - **Эмбиент таба (`tab.ambientAudio`):** при входе в таб (`[TAB:open:Forest]`)
     движок сам делает плавный **audio crossfade** (~1.5–2с) от предыдущего фона к
     эмбиенту новой комнаты.
   - **Автозапуск с секвенцией (`trigger: 'on-seq'`):** например, в табе «Танец»
     лежит трек с флагом запуска под секвенцию — стартует сам при `[SEQ:...]` и
     мягко затухает (`fade-out`) после остановки секвенции или смены таба.
2. **Управление моделью по запросу (строго в рамках диеты токенов):**
   - **Доставка списка доступных треков (инжект):** аналогично `tab.rules` (v27) —
     в текстовый спутник коллажа активного таба дописывается **одна короткая строка**
     ТОЛЬКО если в активном табе есть аудио-ассеты, например:
     `Audio in this scene: waltz_slow (bgm), club_beat (bgm), applause (sfx)`.
     Нет аудио в табе → **0 лишних токенов**.
   - **Единый тег `[AUD:tag]` (и `[AUD:stop]`):** модели не нужно запоминать
     разные команды для музыки и эффектов. Тип (`bgm` vs `sfx`) — свойство самого
     ассета в галерее:
     - `bgm` (фон/музыка): плавный crossfade (1.5–2с), играет в `loop`, вытесняет
       предыдущий `bgm`;
     - `sfx` (эффект: скрип, гром, хлопок, смех): разовый звук (`one-shot`) поверх
       текущего `bgm`, не прерывая музыку.

### 5.2 Узкие места аудио и обязательные мелочи

- **Два независимых канала (`BGM` + `SFX`) и быстрая кнопка 🔇 Mute:** обязательна
  компактная кнопка заглушения в один клик (рядом с контролами проектора или в
  топ-баре) + отдельные ползунки громкости BGM / SFX в настройках.
- **Никаких резких обрывов:** переключение и остановка `BGM` всегда через плавный
  `fade-in` / `fade-out` (~1.2–2с) — иначе переходы сцен звучат дёшево.
- **Изоляция от VLM и RAM:** аудио-ассеты (`.mp3`, `.ogg`, `.opus`, `.wav`) не
  попадают в коллаж-картинку и `ensureBase64()`, подгружаются лениво с диска (как
  видео), а в сетке галереи отображаются отдельной карточкой (`🎵` / `🔊` + мини-кнопка
  `▶` предпрослушки и выбор роли `BGM` / `SFX`).
- **Синхронизация с субтитрами:** при включённом `syncChatTyping` тег `[AUD:sfx]`
  внутри реплики может срабатывать в момент появления соответствующей фразы.

## 6. Бонусные синергии (горизонт)

- **«📸 Извлечь кадры из видео» в галерее** (чисто на `<video>` + `<canvas>` в браузере, без ffmpeg): из одного 10-секундного ролика (240 кадров) за пару кликов получается и видео-ассет, и пачка согласованных статичных поз + выбор характерного кадра обложки (`🖼 На обложку`).
- **Опциональный ассет-портал (`asset.portalTabId`):** необязательное поле у любого обычного ассета (`🚪 Переход в таб: [ — нет — ▾ ]`, хранится по `tab.id`). Срабатывает **только** при вызове ассета моделью (`VPCommandBus`), не от ручного клика в галерее: после показа кадра (или окончания видео/секвенции) автоматически вызывает `_soloOpenTab(portalTabId)` (раскрывая и родительскую категорию, и пересобирая коллаж). В подписи коллажа такой ассет автоматически помечается `tag (→ TargetTab)`. Устраняет частую ошибку 12B–26B моделей (показали дверь, но забыли `[TAB:open:...]`), не создавая новых сущностей.
- **Тонкий мост к ComfyUI API в Asset Studio (отложено):** вместо медленного видео в `sd.cpp` на RDNA 4 — третий режим бэкенда `ComfyUI API` (`http://127.0.0.1:8188`), который использует готовый JSON-workflow пользователя (Export API Format) с подстановкой 3–4 полей (входной кадр, промпт, seed) и фоновой очередью + интеграцией с существующим VRAM-дворецким (`VP_LLAMA.unloadAll()`).

## 7. Порядок реализации

1. **Этап 1 — Секвенции статики (`[SEQ:a,b,c:tempo(:loop|:pingpong)]`, `[SEQ:stop]`): ✅ РЕАЛИЗОВАНО (2026-11-24).**
   Реализовано в `js/visual-projector.js` (`VPTags.parseSeqBody`, `playSequence`, `stopSequence`, `getSequenceState`, зажим `maxFadeSec`, кликабельный статус `▶ SEQ 2/4` в `.vp-player-bar`, события `seq:started` / `seq:step` / `seq:completed` / `seq:interrupted` в `VP_HUB`), `js/director-bus.js` (команда `SEQ`, автостоп при смене `[TAB:...]`), `css/visual-projector.css`, `js/projector-session.js`.
   Подключается по желанию в любом табе через `tab.rules` (0 лишних токенов в базовом манифесте).
2. **Этап 2 — Видео-ассеты (`.mp4`/`.webm` со звуком):** ленивая подгрузка с диска, авто-постер на ~45% + ручной выбор обложки (`🖼 На обложку`) и нарезка кадров (`📸 Сохранить как кадр`), `<video>` в `updateProjectorUI` с `once|loop`, компактный 🔊/🔇 Mute + громкость в Stage, `STORE` в JSZip, постер во всех VLM-каналах, интеграция видео-шагов в `[SEQ:...]`.
3. **Этап 3 — Опциональный портал (`asset.portalTabId`) и аудио-слой (`BGM` + `SFX`):** поле `🚪 Переход в таб` на ассете; ленивые аудио-ассеты в галерее, авто-эмбиент таба / автозапуск под `[SEQ:]`, плавные кроссфейды и опциональный тег `[AUD:tag]`.
4. **Этап 4 — Склейка с FSM, играми и (опционально) ComfyUI API:** подписка игр/FSM на `seq:step` / `seq:completed` / `seq:interrupted` в `VP_HUB` и фоновый мост к ComfyUI API при необходимости.
