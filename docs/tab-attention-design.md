# 🎯 Микро-рефакторинг директорских команд видимости табов (дизайн, обсуждение)

> Дата: 2026-07-28. Статус: ОБСУЖДЕНИЕ, код не тронут.
> Зона: `[TAB:*]` / `[CAT:*]` — парсер (`VPTags.parseDirBody` в visual-projector.js),
> шина (`director-bus.js` → `executeDirectoryCommand` → фасад `VP.gallery.TabsManager`),
> исполнитель (`TabsManager.executeCommand` в gallery-hierarchy.js),
> модель-фейсинг текст (`DEFAULT_MANIFEST_TEMPLATE` в vp-templates.js).

## 1. Карта текущего жизненного цикла

`[TAB:open:Emily]` → VPTags.parseDirBody (только open|collapse, иначе null)
→ шина (queueable ✓) → executeDirectoryCommand → TabsManager.executeCommand:
fuzzyMatch таба по имени → `find.state = 'open'` → **marks: markedForCollage = solo(этот таб)**
→ `generateCollageFromMarkedTabs({reason:'directory-command'})` (async)
→ renderSidebar + persistGalleryData.

**Ключевая находка:** коллаж-марки УЖЕ соло-переключаются при open (спрятанная
половина механики «прожектора», v01-эпоха). Но `state` остальных табов не
трогается: сайдбар и manifest-дерево продолжают показывать все открытые —
внимание размывается на уровне текста, даже когда коллаж говорит соло.

Вторая находка: исполнительный actionMap понимает алиасы (`close`, `fold`,
«закрыть», «свернуть»…), но парсер отсекает всё, кроме open/collapse —
рассинхронизация слоёв.

## 2. Взвешивание

### 2.1 collapse → close
- ЗА: open/close — естественная пара; исполнитель уже понимает `close`.
- ПРОТИВ: `collapse` точнее для аккордеона; грамматика — публичный API модели
  (шаблон учит, старые чаты помнят); чистая косметика.
- Цена реализации: алиас в парсере + канон в тексте шаблона. Риск ~0.

### 2.2 Solo-open КАК ДЕФОЛТ (open X ⇒ остальные collapse)
- ЗА: бесплатная концентрация внимания; манифест худеет до секции; дерево
  и коллаж синхронны.
- ПРОТИВ: **мульти-таб сцена (персонаж+локация) становится невыразимой** —
  второй open убьёт первый; придётся городить add/also/пакетный синтаксис;
  ломает привычку код+модель к аддитивности.

### 2.3 Контрплан: глагол-модификатор `solo` (рекомендация)
Трёхскоростная грамматика без слома:
- `[TAB:open:X]` — аддитивно (поведение как сейчас, коллаж-марка уже соло);
- `[TAB:solo:X]` — прожектор: X ← open, все остальные табы ← collapsed,
  марки ← X, ОДНА перегенерация коллажа, ОДИН persist, ОДИН renderSidebar;
- `[TAB:close:X]` — свернуть X (close = канон; collapse = вечный алиас).

CAT без соло в v1 (семантика категорий с залоченными табами мутная).

## 4. Краевые случаи (зафиксировать в реализации)

- `solo:X` при уже открытом X → остальных всё равно закрыть (детерминизм).
- `close:X` на замаркированном табе → марка сиротеет: v1 оставить +
  задокументировать; v2 (опц.) снимать марку/откатывать обложку.
- Несколько `solo` в одном ответе → очередь шины, побеждает последний (ок).
- CAT solo → не-фича v1; парсить? v1: не принимать (консолеварн как no-match).

## 6. СИНТЕЗ ПОСЛЕ ОБСУЖДЕНИЯ (2026-07-28, направление)

Тезис владельца: простота грамматики — сама по себе скаффолд внимания для
МАЛЫХ локальных моделей: «открыла таб = вошла в сцену». Галерея читается
как FSM: таб = состояние, open = переход, список свёрнутых = меню переходов
(подсказки «куда пойти дальше» по именам табов).

**Решение-кандидат (ждёт «Погнали»):**
- Грамматика остаётся из **4 глаголов, новых — ноль**:
  TAB open/close, CAT open/close. `solo` как отдельный глагол НЕ нужен —
  solo ДЕЛАЕТСЯ дефолтной семантикой `[TAB:open]`.
- `[TAB:open:X]` = атомарный переход сцены: X←open, все остальные табы
  ←collapsed, марки коллажа←X; ОДИН batch: 1×regen коллажа, 1×persist,
  1×renderSidebar (не N дрожаний). Повторный open X «лечит» наследства
  (детерминированное добивание открытых посторонних из прошлых сессий).
- Мульти-видимость — БЕЗ новой грамматики: `[CAT:open:Name]` покрывает
  «персонаж+локацию» (категория = пак сцен; уже работает сегодня).
  Запасной люк будущего: точечный `[TAB:add:X]`, если полевые тесты
  покажут потребность — добавление не ломает 4-глагольную грамматиску.
- close/collapse: канон `close` в доках и шаблоне; `collapse` — вечный
  алиас на парсере и исполнителе (старые чаты/хардкод не ломаются).
  Ручные клики юзера в сайдбаре идут МИМО executeCommand и остаются
  свободными — solo касается только ИИ-команд.
- Текст шаблона: 3 предложения уровня «you enter scenes like rooms»
  (явно про то, что open закрывает остальные, close оставляет «в холле»,
  CAT показывает целый пак).
