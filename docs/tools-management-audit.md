# Аудит системы тулов — 2026-07-29 (v25+, статус: АНАЛИЗ, решение за владельцем)

Запрос владельца: «нам надо разобраться, как менеджить тулами. Сейчас можно либо
включить, либо отключить всю пачку. Если так задумано — ладно, главное чтобы мы не
ошеломляли модель кучей манифестов и подсказок. Каждый тул кидает в модель свою
инструкцию?»

## 1. Механика: как инструкции попадают в модель

`toolsMode: native` → в `send()` (projector-session.js) собирается
`preparedBody.tools = buildOpenAITools()` — массив `{name, description, schema}`
и прикладывается к **каждому запросу**. Для локальных OpenAI-совместимых серверов
(LM Studio) сервер рендерит эти определения прямо в текст промпта по чат-шаблону
модели. То есть это не «манифесты-сообщения» — но эффект тот же: описания и схемы
сидят в контекстном окне **постоянно, в каждом запросе**, хотим мы вызывать тулы
в этом туре или нет.

`toolsMode: off` → ноль токенов, тулы просто не существуют для модели.

**Шторма манифестов НЕТ** — тулы сами по себе в контекст не лезут:
- результат тула едет в контекст только на вызов (tool-сообщение JSON);
- из 9 тулов манифест с TTL пинят лишь два: `character_note` (4 тура),
  `recall_scene` (3 тура); остальные 7 — `ephemeral`;
- контекстная мельница (buildRequestMessages) держит полные tool-данные лишь у
  последних 3 сообщений, старее — сжимает в текстовые саммари.

## 3. Менеджмент: что есть и чего нет

**Уже есть (инфраструктура):**
- реестр умеет `enable(name)`/`disable(name)`, hub-команды `tools:enable`,
  `tools:disable`, `tools:list`, `tools:get-trace` (трейс 50 последних вызовов);
- игровой скоупинг: тулы игры живут и умирают вместе с игрой;
- быстрый тоггл всей пачки в инпут-панели (🔧/🔌, off ↔ native) + селект в
  настройках модели (off / native / text-tags);
- context inspector — показывает состав запроса (можно глазами проверять вес).

**Чего НЕТ:**
- **UI управления отдельными тулами** — включить/выключить конкретный тул нельзя
  (только вся пачка);
- **персистентности**: флаг `enabled` живёт в рантайм-памяти реестра — F5
  сбрасывает любые отключения в дефолт «всё включено»;
- диеты у тяжёлых описаний (см. п.2).

## 4. Найденный мёртвый код: режим `text-tags`

Опция `text-tags` есть в селекте настроек и в комментарии DEFAULT_MODEL, но:
- сессия прикладывает тулы только при `toolsMode === 'native'`;
- `buildServicesCard()` (компактная [SERVICES] карточка, ~700t) **нигде не
  вызывается** — мёртвая сборка;
- быстрый тоггл переключает только off ↔ native.

То есть выбор «Text tags [SERVICES]» сегодня эквивалентен off. Вердикт:
учитывая «текстовые модели уходят в прошлое» (владелец, 2026-07-29) — **скрыть
опцию** (или снабдить пометкой «не реализовано»), карточку не удалять: дёшево
воскресить при нужде.

## 5. Варианты (на выбор владельца)

- **A. Минимализм:** ничего не строить; подстричь описания `scene_navigate`
  (−30%) и `configure_prompt_studio`, скрыть text-tags. Пачка остаётся атомарной.
- **B. Пер-тул менеджмент (рекомендағы):** секция «Tools» в настройках модели —
  список с чекбоксами, счётчиком ~токенов напротив каждого и суммарным весом;
  `disabledTools[]` персистится в modelConfig и применяется к реестру после
  гидрации. Инфраструктура готова — работа ~80% UI. Плюс диета из A.
- **C. Пресеты поверх B:** готовые наборы («Джентльмен»: dice+describe+navigate;
  «Память»: +recall+note; «Студия»: +studio), переключаемые одной кнопкой.

## 6. РЕШЕНИЕ ВЛАДЕЛЬЦА (2026-07-29): **B** — реализовано в v26

- **Персистентность:** `modelConfig.disabledTools[]` — истина через F5. Крутилки:
  (а) boot-синк `applyDisabledToolsFromConfig()` в projector-session.js (статичные
  тулы регистрируются до гидрации — догоняем после); (б) born-disabled в
  `VP.tools.register` (поздние игровые регистрации рождаются уже выключенными).
- **UI:** секция 🧰 Tools в панели модели — строка-комптоид
  «N/M on · ≈X tok in every request (native)», чекбокс на каждый тул с
  ~токенами напротив, dim .off-строки, тост «saved». Изменения мгновенно влияют
  на `buildOpenAITools()` (enabledOnly-фильтр реестра) — следующий запрос уже
  легче. Быстрый тоггл 🔧/🔌 целой пачки нетронут.
- **Диета:** scene_navigate 446→306 desc.ch (−31%), configure_prompt_studio
  614→406 (−34%); пачка 1361→1274 ≈токенов (−6.4%).
- **text-tags:** опция скрыта (мёртвая), миграция `text-tags → off` в
  normalizeState; `buildServicesCard` оставлен в коде — дешёвый резерв.
- **Без новых манифестов:** цены — 1 число + 1 массив строк в modelConfig.
- Тесты: smoke-session-panels +16 (секция B2 + offline-note + скрытая опция),
  smoke-scene-navigate-tool +5 (секция G: born-disabled + отказ исполнения).
