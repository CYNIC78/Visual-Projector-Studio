# 🗺️ Карта модулей VP Studio (хозяева ↔ спутники)

> Шпаргалка «кто есть кто» без переименований файлов (имена зашиты в index.html,
> fail-fast сообщения, шапки и бэкапы — так что держим карту здесь).
> Актуально на билд 16 (2026-07-28). Обновляем при каждом новом выносе.

## Как читать

- **ХОЗЯИН** — большой модуль-оркестратор. Регистрирует фасад на `window.VisualProjector`.
- **Спутник** — выделенный домен хозяина. По большей части наш рефакторинг (v01–v16).
- Два паттерна загрузки:
  - **`ДО`** — спутник грузится РАНЬШЕ хозяина, регистрирует `window.VP_X`,
    хозяин на мосту вызывает `init(deps)` (fail-fast, если порядок сломан);
  - **`ПОСЛЕ`** — спутник грузится ПОСЛЕ хозяина, захватывает фасад и
    регистрирует свой API; хозяин зовёт его через безопасные делегаты.

## Золотые правила швов (работаем вслепую)

1. Спутник **никогда** не шарит состояние в обход `State` из фасада/инициализации.
2. Всё, что спутнику нужно от хозяина — в `init(deps)` с fail-fast списком имён.
3. Верификация выноса = побайтовый diff тела + `node --check` + смоуки; смоук обязан
   **рендерить** компонент целиком (урок v16).
4. Откат любой версии = распаковать `backups/NN-*.zip` поверх.
