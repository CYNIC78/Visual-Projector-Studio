## Главная проблема: разнобой в терминах

Одна и та же сущность зовётся четырьмя именами. Фиксируем **один** канон:

| Сущность | Как звалось в UI | **Канон (EN)** | Почему |
|---|---|---|---|
| Коллаж-превью для модели | «Витрина» (7), «Gallery View» (23), «коллаж» (1), «visual inventory» (1) | **Gallery View** | Уже доминирует (23 из 32) и совпадает с тем, что видит модель в манифесте (`[CURRENT GALLERY VIEW]`). Один термин в UI и в контексте модели = меньше путаницы. |
| Вкладка галереи | «таб» (21), «вкладка» (3) | **tab** | Совпадает с командой `[TAB:open:…]`. |
| Категория | «категория» (12), «пак» (4) | **category** | Совпадает с `[CAT:open:…]`. «Pack» оставляем только в прозе-описаниях, не в названиях кнопок. |
| Ассет | «ассет» (21) | **asset** | — |
| Черновик генерации | «черновик» (2), «драфт» | **draft** | Совпадает с полем `_draft`. |
| Кадр на проекторе | «кадр» (6) | **frame** | Совпадает с `Projector frame:` в манифесте. |
| Активная сцена | «сцена» (9) | **scene** | Совпадает с FSM-терминологией. |

## Канон состояний FSM (важно — это ядро UX)

| Точка | state | **EN в UI** | Смысл |
|---|---|---|---|
| 🟢 | `open` | **Active scene** | комната, где идёт действие; на Gallery View |
| 🟡 | `collapsed` | **Collapsed** | кандидат меню; модель видит только имя |
| 🔴 | `locked` | **Hidden from model** | верстак пользователя |

Глаголы: **Enter** (войти в сцену) · **Collapse** · **Hide from model** / **Unhide**.
Не использовать «Lock/Unlock» в UI — «Hidden from model» точнее объясняет смысл
пользователю (лок — это внутреннее имя состояния, а не то, что важно человеку).

## Плюрализация

5 строк содержат славянские формы `таб(ов)`, `ассет(ов)`, `эффект(ов)`, `черновик(ов)`.
В английском — простое правило, применяем хелпер-паттерн прямо в строке:

```js
`${n} asset${n === 1 ? '' : 's'}`
```

Отдельную библиотеку не тянем.

## Стиль

- **Sentence case** для предложений в тостах: `Gallery View updated`.
- **Title Case** для пунктов меню и кнопок: `Build Gallery View`, `Hide from Model`.
- Эмодзи-префиксы сохраняем как есть (они уже интернациональны): `🖼️`, `🔒`, `🎬`.
- Тосты — короткие, без точки в конце, если это одна фраза.
- Многоточие `…` для процессов: `Building Gallery View…`.
- Не переводить дословно: `Витрина в кулуарах` → `Gallery View is backstage`
  (метафора рабочая, владелец её любит — сохраняем).
